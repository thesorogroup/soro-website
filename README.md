# Soro Group Website

Netlify-ready static site.

- All pages use `assets/styles.css` as the single master stylesheet.
- All pages use `assets/site-routing.js` for shared modal/form behavior and inquiry routing.
- Shared header/footer markup is kept consistent across pages.
- About-specific rules are grouped under `ABOUT PAGE` in the master stylesheet and scoped with `.soro-about-page`.
- About artwork is stored in `assets/` as optimized transparent PNG files.
